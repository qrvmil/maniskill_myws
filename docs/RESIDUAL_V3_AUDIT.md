The original PLD training code/settings are not fully released in these references. SERL's generic pixel factory also contains an obsolete EncodingWrapper constructor argument; the functioning DrQ pretrained path is the topology reference. No target-trained weights or target observations are used in learning. Base fallback, synchronous learner and finite-horizon terminal masks remain explicit experimental choices, not proven exact PLD implementation details.

Implementation details: V3 Dense layers use SERL Xavier-uniform weights/zero biases and LayerNorm epsilon1e-6. Auxiliary Cal-QL uses the reference full-action proposal/temperature/Adam learning rates; compatible SERL visual/MLP architecture and sequential critic/actor updates remain a port, not bitwise Cal-QL parity. Online optimizer counters restart after offline initialization. PLD Table5 specifies AdamW but no decay coefficient; V3 explicitly retains weight_decay0.01. SERL make_optimizer defaults to Adam when weight_decay is omitted, so the optimizer type follows PLD while the coefficient is an unpublished-setting choice.

Reference-review clarifications (not correctness failures): SERL ensembles the MLP backbone then shares its final scalar Dense readout; this port retains independent final Q projections. SERL samples next-state entropy separately for temperature; this port reuses detached current-state actor log-probability, a standard SAC estimator. Visual projection initialization uses Xavier in V3 rather than Flax Dense's default LeCun initialization. These are explicit remaining differences, not exact numerical SERL parity. They were reviewed during initialization; no outcome-driven architecture changes are made to run A.
